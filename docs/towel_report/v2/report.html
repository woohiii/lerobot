수건 접기 정책 학습 보고서 (v2)

로봇 두 팔이 수건을 반으로 접고 대문접기까지 하는 단일 정책 · SO-101 양팔 로봇 · 2026-09-30 기준

1. 한눈에 보기

  • 무엇을: 로봇 두 팔이 펼쳐진 수건을 스스로 반으로 접고, 이어서 양쪽을 안으로 접어 대문접기까지 마무리하게 만든다.
  • 어떻게: 사람이 로봇 팔을 직접 조작한 시연 46개(복제 포함 97개, 약 16만 프레임)를 보고 따라 하는 AI 모델(ACT)을 학습한다. 반접기부터 대문접기까지 끊지 않고 이어서 배운다.
  • 지금은: 학습 준비 단계이다. 시연 데이터를 학습용으로 정리하고 있으며, 끝나면 모델을 약 3시간 학습한다.
  • 성공 여부는: 실제 로봇으로 같은 조건에서 30회 시험해 확인한다. 성공률은 아직 측정 전이다.

2. 무엇을 만드는가

아래 네 장면은 실제 시연 영상에서 뽑은 것이다. 펼친 수건을 반으로 접고, 이어서 양쪽을 안으로 접어 대문 모양으로 마무리한다.

① 펼친 수건 → ② 반으로 접기 → ③ 양쪽을 안으로 접는 중 → ④ 대문접기 완성

왜 어려운가

  • 수건은 모양이 계속 변하는 물체라서, 같은 동작을 해도 매번 다르게 접힌다.
  • 두 팔이 서로 맞춰 움직여야 한다.
  • 그래서 규칙을 프로그램으로 짜는 대신, 사람의 시연을 보여주고 따라 하게 만든다.

3. 무엇으로 가르치는가 (데이터)

단계개수설명
원본 시연72개원격 조작으로 수집. 각 시연의 동작 단계 경계를 사람이 검수
조건에 맞는 원본46개반접기와 대문접기를 모두 담고, 수건이 깨끗이 펼쳐진 상태에서 시작
복제 포함97개 / 159,084프레임조건별로 균형 있게 복제해 늘림
학습 / 평가79개 / 18개원본 시연 단위로 나눠, 복제된 같은 영상이 양쪽에 섞이지 않음
  • 설계의 핵심: 한 시연을 반접기 시작 프레임부터 대문접기 끝 프레임까지 끊지 않고 하나로 이어 잘랐다. 모델이 두 동작 사이의 전환(반으로 접은 수건을 이어서 접는 방법)까지 익힌다.
  • 제외한 것: 방향을 다시 잡아야 하는 시연 25개와 그 외 1개는 뺐다.

4. 학습 방법

사람의 시연을 따라 하도록 ACT 모델을 학습한다. 기술 설정은 다음과 같다.

항목값
모델ACT (chunk_size 100, n_action_steps 100, VAE 사용, dim_model 512)
학습량40,000스텝, 배치 4 (데이터를 약 1.2바퀴)
점검10,000스텝마다 평가, 5,000스텝마다 저장. 평가 손실이 다시 오르면 이전 체크포인트 사용
이미지 증강밝기·대비·채도·색조, 작은 이동·회전 (좌우 반전 없음)
환경8GB GPU, 초당 약 4.4스텝, 평가 포함 약 3시간

40,000스텝은 20,000스텝이 데이터를 0.6바퀴만 도는 점을 보고 정한 값이며 논문 기준값이 아니다.

5. 현재 상태와 검증 계획

순서내용상태
1시연 데이터를 학습용으로 정리진행 중
2AI 모델 학습 (중간 점검에서 성능이 떨어지면 이전 상태로 되돌림)다음 (약 3시간)
3실제 로봇으로 같은 조건에서 30회 시험그다음
4실패한 경우를 유형별로 분석하고 가상 환경(MuJoCo)에서 보강이후
성공률측정 전 / 30회
성공 기준시험 전에 확정한다 (사람 개입 없이 끝까지 접는 것을 기본안으로 검토)
결과시험이 끝나면 이 표에 채운다
  • 왜 실제 시험이 필요한가: 학습 중 오차가 줄어도 로봇이 실제로 잘 접는다는 보장은 없다. 30회 시험이 이 설계가 맞았는지 알려주는 유일한 최종 검증이다.
