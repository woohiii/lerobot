수건 접기 정책 학습 보고서 (v2)

펼친 수건 반접기 + 대문접기 단일 정책 · SO-101 양팔 로봇 · LeRobot ACT · 2026-09-30 기준

1. 요약

펼쳐진 수건을 반으로 접은 뒤 양쪽을 안으로 접는 대문접기까지, 하나의 ACT 정책으로 수행하도록 학습한다. 원본 46개 에피소드에서 복제 포함 97개 에피소드(159,084 프레임)를 만들었고, 학습 79개와 평가 18개로 나눴다. 이 데이터를 40,000스텝 학습한 뒤 실제 로봇 30회 시도로 성공률을 측정한다.

아직 실제 로봇에서 측정한 성공률은 없다. 학습 손실이 내려가도 성공률이 오른다는 보장은 없으므로, 30회 평가가 이 설계의 유일한 최종 검증이다.

2. 과제와 데이터

  • 과제 문구: "Fold the flat towel in half, then fold both sides in like a gate fold".
  • 원본: 원격 조작으로 수집한 72개 에피소드. 각 에피소드의 동작 단계 경계(프레임 위치)를 사람이 검수한 매니페스트를 사용했다.
  • 선택 기준: 반접기와 대문접기 단계를 모두 가지며 수건이 깨끗이 펼쳐진 상태에서 시작하는 46개. 방향을 다시 잡아야 하는 25개와 그 외 1개는 제외했다.
  • 에피소드 정의: 반접기 시작 프레임부터 대문접기 끝 프레임까지 끊지 않고 하나로 이어 잘랐다. 정책이 두 동작 사이의 전환까지 학습한다.

항목값

평가 데이터는 복제본이 아니라 원본 에피소드 단위로 나눠, 같은 영상이 학습과 평가에 섞이지 않게 했다.

3. 학습 설정

항목값
정책ACT (chunk_size 100, n_action_steps 100, VAE 사용, dim_model 512)
학습 스텝40,000 (데이터를 약 1.2바퀴)
배치 크기4, 혼합정밀도(AMP)
이미지 증강밝기·대비·채도·색조, 작은 이동·회전 (좌우 반전 없음)
체크포인트 / 평가5,000스텝마다 저장, 10,000스텝마다 평가
속도와 시간8GB GPU에서 초당 약 4.4스텝, 평가 포함 약 3시간

40,000스텝은 20,000스텝이 데이터를 0.6바퀴만 도는 점을 보고 정한 값이며, 논문 기준값이 아니다. 영상 타임스탬프 허용오차는 --tolerance_s=0.001로 설정했다.

4. 평가 계획

  • 같은 조건으로 30회 시도하고, 성공 기준을 시도 전에 정해 성공률을 측정한다(로봇, 수건, 사람이 필요).
  • 학습 중 평가 손실이 다시 오르면 과적합으로 보고 이전 체크포인트를 쓴다.
  • 실패한 시도는 유형별로 분류해 원인을 분석하고, MuJoCo 수건 시뮬레이션에서 시나리오를 보강한다.

5. 위험

  • 성공률 미측정: 손실값만으로 성공을 판단할 수 없다.
  • 학습량: 1.2바퀴는 충분하지 않을 수 있어, 결과에 따라 스텝을 늘리거나 이어서 학습할 수 있다.
  • 디스크: 여유가 20GB대라 다른 작업의 대용량 쓰기가 있으면 데이터 절단과 학습이 멈출 수 있다.

6. 확인 방법

  • 데이터 절단 진행: outputs/train/cut_half_to_gate_fold.log 의 [N/97].
  • 전체 진행: outputs/train/half_to_gate_chain.log 의 CUT_DONE, START, TRAIN_DONE.
  • 학습 상태: outputs/train/act_half_to_gate_fold_v1.log 의 step 과 loss.
