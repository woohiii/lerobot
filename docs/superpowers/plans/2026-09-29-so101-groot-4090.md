# SO-101 GR00T N1.7 4090 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide a reproducible, leak-free GR00T N1.7 training workflow for the private 150-episode bimanual SO-101 towel dataset and a fail-closed remote evaluation client.

**Architecture:** A training helper validates the pinned dataset, derives a deterministic source-group split, and emits preflight/smoke/full commands. GR00T preprocessing normalizes mixed camera resolutions before stacking. A dedicated evaluation wrapper uses the existing async client while enforcing observation, action, latency, and motion safety gates.

**Tech Stack:** Python 3.12, LeRobot, PyTorch, GR00T N1.7, Hugging Face Hub, pytest, gRPC async inference.

**Spec:** Approved in-chat plan from 2026-09-29.

## Global Constraints

- Dataset: `Woohi123/towel_fold_v1_balanced150` at revision `2b606ccb6b4eb45e1290447a1077504d1d56122a`.
- Dataset contract: 150 episodes, 535475 frames, 12D bimanual state/action, four visual features, three exact task strings.
- Split: seed 42, all materialized train episodes plus 5 unique-source validation representatives per condition; no source identity may cross splits. The wrinkled pool has 22 source demos replicated to 50 stored episodes, so its train count can be below 40.
- Training: GR00T N1.7 `new_embodiment`, chunk/action horizon 16, relative actions excluding both grippers, BF16 parameters, batch 1, gradient accumulation 8.
- Runtime: fail closed on stale/malformed observations, non-finite or wrong-dimensional actions, excess latency, or unsafe relative targets.
- Dataset and model repositories remain private.

## Review Focus

- Deterministic replication provenance and zero train/validation source overlap.
- Mixed-resolution camera ordering and image value/rank preservation.
- Shell-safe command serialization for episode lists and gripper exclusions.
- 24GB smoke/full separation and explicit 40GB+ fallback criteria.
- No physical action transmission in self-check or dry-run modes.
